# NoVir

**NoVir is a free Windows recovery tool designed to help restore your system after malware infections and system failures.**

NoVir helps restore access to blocked Windows tools, repair damaged system settings, and clean up some consequences of malware without reinstalling Windows.

> ⚠️ **NoVir is not an antivirus.** It does not scan files for malware or provide real-time protection.

## Features

* 🔒 Restore access to blocked Windows tools
* 🚀 Manage Windows startup programs
* 🗂️ Browse hidden and system files
* 🔓 Unlock files locked by running processes
* 🛠️ Access advanced Windows recovery tools
* ⚙️ Repair WMI and Windows Update
* 🔧 Restore Safe Mode and file associations
* 💻 Repair various Windows system settings

## Requirements

* Windows 10 or Windows 11
* Administrator privileges recommended
* Internet connection is not required for the main features

## Installation

Download the latest release and run `NoVir.exe`.

For advanced recovery operations, run NoVir as administrator.

## Warning

Some advanced tools can modify important Windows settings, the bootloader, registry, or disk configuration.

**Use these features carefully and create a system restore point or backup before making major changes.**

## Privacy

NoVir is designed to work locally on your computer.

It does not require registration and does not intentionally collect or transmit personal data.
